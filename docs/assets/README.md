# Demo recording

`demo.gif` is a screen recording of the Android sample app, captured on an API 36 arm64 emulator while preparing 1.2.0. It selects a 100,000-byte WebP limit, compresses the included Apollo 17 photograph, and moves the comparison divider.

The GIF was resized from the original recording. The displayed times belong to that emulator; use the [benchmark methodology](../../benchmark/README.md) for measurements. Photograph credit: NASA/Apollo 17 crew; [source and usage](../../benchmark/SOURCES.md).
